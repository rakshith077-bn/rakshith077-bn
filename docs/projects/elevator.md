## Smart Elevator Control System using SimuliIDE and Arduino IDE

The page entails a literature review report and a practical report. 

The practical report demonstrates the nature of the developed system Smart Elevator System using SimuliIDE and Arduino. The overview of the developed system is enclosed within the given report. 

!!! note "Note:"
      This page entails to give viewers a summary of the enclosed report.

The literature review report is structured to draw context and lessons from peer-reviewed published research across five fundamental aspects and areas essential to the development of a Smart Elevator Control System, and are as follows:

* The modeling and design of **Finite State Machines** (FSMs) for simultaneous sequential control, helping establish the fundamentals required for handling the numerous elevator transitionary states.
* The working of real-time scheduling algorithms and task management, which are essential for ensuring critical tasks meet their deadlines and that the activities are executed, enabling robust method of handling tasks
* The integration of __event-driven__ systems and __interrupt-driven__ control, enables establishing progressive path towards responsive handling of multiple asynchronous floor calls and handle potential overloads at the same time.
