## RAG Chatbot for Medical Q&A

!!! danger "Note:"
    `Undergoing Modifications` Check back in a few days!.

The project demonstrates the development of a Retrieval-Augmented Generation (RAG) chatbot for answering medical questions using scientific literature Relevant contexts are retrieved from PubMed via semantic search, then passed to a large language model to generate grounded and context-aware answers.
